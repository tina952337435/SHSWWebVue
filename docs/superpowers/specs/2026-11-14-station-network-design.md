# 站网管理模块设计说明

- 日期：2026-11-14
- 项目：SHSWWebVue（上海市水文行业综合业务管理系统，纯前端演示版）
- 依据：《长江口、省市边界水文监测站网信息化项目升级改造业务功能需求（站网管理科）》束整理稿 + 1 月 16 日站网科专题讨论会纪要
- 目的：下周向客户演示的站网管理设计版本

## 1. 目标与范围

在水资源评价模块已确立的视觉与交互规范下，新建"站网管理"二级菜单，覆盖站网管理科提出的 4 个功能模块、9 个功能点。

本期实现 5 项，**站网数据智能问答本期不做**（菜单不出现，需求留档）：

1. 站网GIS（含可视化测站、专题图导出）
2. 测站管理
3. 水文统计调查（数据录入 / 数据审核 / 综合查询）
4. 工单系统（工单管理 / 巡检记录 / 统计分析）
5. 船舶管理（船舶台账 / 用船申请 / 统计分析）

对应需求原文的落点：

| 需求 | 落点 |
|---|---|
| 站网分布图按自定义属性导出 | 站网GIS → 导出专题图 |
| 图例规范化 | 站网GIS 图例分区（点/面/线） |
| GIS 悬停看基本信息、点击看综合信息、不跳页 | 站网GIS 悬停提示 + 右侧可视化测站面板 |
| 测站标签化、自定义属性统计导出 | 测站管理 |
| GPS 经纬度显示、城建坐标另存、辅助观测项目 | 测站管理详情 / 台账列 |
| 水文统计年报填报、审核、查询 | 水文统计调查 |
| 巡检记录表模板、工单多维统计 | 工单系统 |
| 船舶证件临期、用船申请线上化、报表 | 船舶管理 |

## 3. 站网GIS（`src/views/zw/StationGIS.vue`）

### 3.1 布局

- 全屏地图（复用一张图浅色底图 + 城建坐标投影），右侧面板浮在地图之上（`position:absolute`，480px），默认收起，右缘有竖排"测站"标签；开合不改变地图视野。
- 左上悬浮条件栏 `.gis-cond`（白底圆角，浮于地图）：站类下拉、水文要素下拉、行政区下拉、水利片区下拉、关键字输入。
- 左上第二行图层开关 `.gis-layers`：基本站 / 专用站 / 区管站 / 共享站 / 水利片区 / 行政区 / 站名。
- 右上"导出专题图"按钮；右下比例尺；左下"图例"卡（默认展开，规范化分区）。
- 图例内容：
  - 点符号：● 水位站（蓝 `#017de4`）、■ 雨量站（青 `#16b8b0`）、◆ 水质站（紫 `#7b8cff`）、▲ 流量站（绿 `#26a869`）、○ 共享站（空心蓝）
  - 面：水利片区（细蓝边）、行政区（选中高亮）
  - 线：片区边界
  - 状态：灰点 = 离线、蓝点 = 在线

### 3.2 分级显示

- `view.w > MW * 0.42`（全市视野）：按行政区聚合显示气泡，气泡内写该区当前筛选下的站数，点击气泡缩放到该区。
- `view.w <= MW * 0.42`：展开单站；`view.w <= MW * 0.14`：显示站名标签。
- 站点按主要素取形状与颜色；离线站灰化；选中的站点放大 + 脉冲圈。

### 3.3 交互

- 悬停：`.map-tip` 显示站名、站码、站类、监测要素、实时值（水位/流量/雨量）、行政区、水利片区、管理单位。
- 点击：右侧"可视化测站"面板打开，地图上站点高亮；面板不跳页。
- 面板页签：
  1. **基础信息**：站码、站名、站类、建站年份、河道、行政区、水利片区、管理单位、GPS 经纬度、城建坐标、辅助观测项目；上下游关系（同河道上按经纬度排序取前/后站，可点击切换）。
  2. **实时工况**：当前水位 / 流量 / 雨量三张小卡 + 近 24h 迷你过程线（复用 `BarChart`）+ 设备在线状态列表（遥测终端、水位计、雨量计、备用电源）。
  3. **视频监控**：2×2 视频占位格（灰底 + 站名 + "实时视频"角标 + 时间戳），点击提示"演示环境未接入视频流"。
  4. **特征值**：历史最高水位、历史最大流量、历史最低水位及其出现时间；近 5 年特征值表。
  5. **设备与巡检**：设备台账表（设备码、名称、型号、安装日期、上次更换、状态）+ 最近 5 条巡检记录。

### 3.4 站点沿革（2026-11-14 新增）

- **默认仍是 2026 年最新布局，时间轴不常驻**：点地图右上「站点沿革」按钮才展开底部时间轴，按钮变为「退出沿革」，退出即回到 2026。
- 时间轴 **1949—2026**：可拖动、可播放；选中年份后，地图气泡/站点、右侧测站明细、专题图导出都只按「当年在册站」计算。
- 当前 718 个在册站在 1949—2025 之间逐步建站；另外生成 **26 个历史撤站**（`startYear` / `endYear`），只在存活年份出现，因此 2026 年仍为 718 站。
- 「沿革记录」弹窗：按年份倒序列出 **建站 / 迁站 / 更名 / 撤站** 事件（约 900 条），支持按类型筛选，点击任一条把时间轴跳到该年份。
- 数据接口：`CLOSED_STATIONS`、`ALL_STATIONS`、`stationsAtYear(year)`、`EVOLUTION_EVENTS`（均在 `src/data/stationNetwork.js`）。

### 3.5 导出专题图

弹窗 `专题图导出`：

- 标题（默认"上海市水文站网分布图"）
- 范围：当前视野 / 全上海
- 图面要素复选框：站点、站名、水利片区、行政区、图例、比例尺、制图日期
- 右侧 A4 纵向缩略预览
- 导出 PNG / SVG

实现：以当前筛选结果构造独立 SVG（白底 + 矢量要素 + 标题栏 + 图例 + 比例尺），序列化为字符串后：

- SVG：直接 Blob 下载。
- PNG：`Image` 加载 SVG data URL → 绘制到 canvas → `toDataURL`。**不含在线瓦片底图**（跨域限制），已在设计阶段与用户确认采用矢量专题图。

## 4. 测站管理（`src/views/zw/StationLedger.vue`）

### 4.2.1 管理台改造（2026-11-14 客户走查）

客户反馈「筛选要摊开、页面要体现管理而不是数据查询」，据此调整：

- **筛选全部摊开、不用下拉**（客户强调只摊开展示、不加新维度）：第一行 关键字 + 查询 / 重置 / 导出Excel / 导入Excel；其后每行一个条件，全部用 chips：「站类」「统计维度 + 行政区/水利片区」「管理单位」「监测项目」（监测项目多选，其余单选）。**行政区与水利片区是两个维度，只能二选一**：先选维度，下面只展开对应的一组 chips，切维度时清空两者。管理单位的「河道管理所」聚合为一项，匹配所有 xxx河道管理所。
- **管理待办**：信息待完善、当前离线、已停用站点三张可点击卡片，点击即筛出待处理测站。
- **管理动作**：行内编辑属性（站名/站类管理/监测项目/辅助观测/管理单位/启停）、启用停用、变更记录抽屉；勾选后批量启用/停用/打标签；新增测站仍提示后台办理（权限回收）。
- **导入导出**：导出当前筛选结果 CSV；导入弹窗提供模板下载与文件选择（演示流程，正式版对接解析与后台审核）。
- 去掉两张分析图，把版面让给待办与台账；自定义统计报表维度仍为 行政区 / 水利片区 / 站类 / 管理单位。
- 数据里预留了 `mgmt`（站类管理）与 `system`（水系）字段，但本页筛选与表格**不使用**，避免引入客户没要的条件。

### 4.3 详情弹窗

分组：基本信息（站码/站名/站类/建站年份/状态）、空间位置（经纬度、城建坐标、行政区、水利片区、河道、地址）、监测项目（主监测要素、辅助观测项目 chips）、管理信息（管理单位、负责人、联系电话）。
底部提示："新增、删除及站码变更在后台管理端操作，本页面仅提供查询与属性维护。"

### 4.4 自定义统计报表

弹窗：统计维度（行政区 / 水利片区 / 站类 / 管理单位）× 统计指标（测站数、基本站数、专用站数、水位站数、雨量站数、流量站数、水质站数）。生成交叉表，行 = 维度值，列 = 指标，末行合计；可导出 CSV。

## 5. 水文统计调查（`src/views/zw/StationSurvey.vue`）

页内三页签：数据录入 / 数据审核 / 综合查询（`keep-alive` 保留各自状态）。

### 5.1 数据录入

- 条件栏：年度（2024/2025/2026）、填报单位（上海市水文总站 + 10 个区水文站）、报表章节、填报状态徽标。
- 左侧 220px 章节树：一、测站基本情况；二、水文要素观测；三、资料整编成果；四、人员与经费。
- 右侧可编辑表：指标名称 / 单位 / 上年同期 / 本年填报（input）/ 同比 / 数据来源。
- 数据来源值：`自动带入`（取自站网台账统计，蓝色小标签）/ `手工填报`。
- 工具按钮："从站网自动带数"（把来源为自动带入的行刷新为台账实时统计）、"对比上年"开关、"保存草稿"、"提交审核"。
- 保存草稿后页签显示"草稿已于 HH:mm 保存"。

### 5.2 数据审核

- 顶部 4 卡：强制性错误、合理性问题、已处理、审核状态。
- 左侧规则卡（约 6 条）：必填项校验、数值区间校验、同比异常（±30%）、分项合计校验、与站网台账一致性、上年数据衔接。
- 右侧校核结果表：等级徽标（强制性错误红 / 合理性问题橙）、指标、错误描述、当前值、建议、状态（待处理/已处理）。
- "一键审核"重新生成结果；"导出"错误清单。

### 5.3 综合查询

- 条件栏：年度、单位。
- 年报格式分组表头表格（与录入章节一致，只读）。
- 下方"自定义指标对比"：指标多选 chips（最多 4 项）+ 历年趋势柱状图（2019–2026，多年平均以折线呈现）。
- 导出。

## 8. 数据文件

全部为确定性生成（同输入同结果，刷新不变），不引入接口。

### 8.1 `src/data/stationNetwork.js`

导出 `STATIONS`（718 条）、`STATION_STATS`、`stationByCode(code)`、`upDown(code)`、`feat5y(code)`、`deviceList(code)`、`inspectHistory(code)`。

站点字段：

```
code 站码(8位) / nm 站名 / cls 站类 / tags[] 属性标签 / elems[] 监测要素
riv 河道 / dist 行政区 / slp 水利片区 / unit 管理单位
lon lat 经纬度 / cx cy 城建坐标 / year 建站年份 / aux[] 辅助观测项目
status 在线|离线|维护 / q wrz grz rain 实时值 / main 主要素
```

生成规则：

- 以现有 35 个真实站为种子，其中 `sz=true` 的作为"基本站"（国家基本站），其余作为共享站/省界站。
- 其余站点按行政区面积权重分配到全市 718 站；坐标在该区多边形内用种子随机采样（`DIST` 多边形 + 种子 LCG），保证点落在辖区内。
- 站名 = 区内真实地名 + 要素后缀（水位站 / 雨量站 / 水文站 / 闸(闸内) / 泵站），同一地名下用河道名区分，保证唯一。
- 水利片区用 `public/data/slp.json` 点在面判断，落在界外时取最近片区质心兜底。
- 城建坐标由 `mapProj.js` 的 `cjX/cjY` 计算。
- 实时值、特征值、设备、巡检历史均用 `hash(code)` 派生。

### 8.2 `src/data/stationSurvey.js`

导出 `SURVEY_YEARS`、`SURVEY_UNITS`、`SURVEY_SECTIONS`（4 章 18 项指标）、`surveyRows(year, unit, section)`、`auditRules()`、`auditResults(year, unit)`、`historySeries(indicators)`。

### 8.3 `src/data/workOrders.js`
